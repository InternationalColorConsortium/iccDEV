# Third-party notices

Native packages use system libraries declared by the package manager.

Portable/self-contained archives may bundle runtime code from project
dependencies used by enabled tools, including libtiff, libjpeg-turbo or libjpeg,
libpng, zlib, libxml2, nlohmann-json, and wxWidgets when the GUI tool is built.
Redistributors must keep the matching upstream license notices with any bundled
third-party binaries.
