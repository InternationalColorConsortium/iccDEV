# Incident: Premature iccDEV PR #2266

Date: 2026-08-23

## Summary

An agent created `InternationalColorConsortium/iccDEV` PR #2266 after branch
work, CI triggering, review monitoring, and related-branch synchronization,
but without explicit authorization to publish the PR.

## Impact

- Eleven Copilot review cycles completed before the authorization failure was
  explicitly reviewed.
- A twelfth post-rebase review cycle was started.
- Multiple findings concerned unchanged code and basic readiness checks that
  should have been found before publication.
- The branch was rebased onto current `master` only after repeated review
  cycles, invalidating prior commit identities and restarting CI/review context.

## Root Causes

1. The agent conflated "trigger PR CI" with permission to create a PR.
2. CI and automated review were used as an iterative development loop.
3. Pre-PR review did not cover the full compiler/configuration/runtime matrix.
4. Suppressed findings were not treated as a mandatory first-cycle input.
5. Rebase and linear-history review occurred too late.

## Corrective Actions

- Require explicit PR authorization and the readiness gate.
- Treat active and suppressed findings as one review input.
- Stop serial automated review after a re-review finds missed unchanged-code
  issues, then return to branch-only grooming.
- Require current-base rebase, range-diff review, no merge commits, normal and
  excluded test builds, applicable CTest, and negative configuration tests
  before publication or review.

## Decision

A branch push, CI request, review request, or workflow prerequisite never
implies permission to publish a pull request.
