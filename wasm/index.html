iccDEV WASM Tools

ICC color profile tools compiled to WebAssembly. All processing runs locally in your browser -- no server, no uploads.

Profile Inspection

iccDumpProfile

Dump ICC profile header, tag table, and detailed tag contents.
Input: ICC profile (.icc, .icm)

iccRoundTrip

Validate PCS round-trip fidelity of an ICC profile.
Input: ICC profile

Conversion

iccToXml

Convert a binary ICC profile to human-readable XML.
Input: ICC profile → Output: XML

iccFromXml

Build an ICC profile from an XML specification.
Input: XML → Output: ICC profile

iccFromCube

Create an ICC profile from a .cube 3D LUT file.
Input: .cube LUT → Output: ICC profile

Color Management

iccApplyProfiles

Apply ICC profiles to transform pixel data between color spaces.
Input: TIFF + ICC profiles

iccApplyNamedCmm

Apply ICC transforms using named color management.
Input: ICC profiles + config

iccApplyToLink

Create a device link profile from a sequence of ICC profiles.
Input: ICC profiles → Output: device link

iccApplySearch

Search for optimal ICC transform paths.
Input: ICC profiles + search config

Image Analysis

iccTiffDump

Dump ICC profile embedded in a TIFF image file.
Input: TIFF image

iccPngDump

Dump ICC profile embedded in a PNG image file.
Input: PNG image

iccJpegDump

Dump ICC profile embedded in a JPEG image file.
Input: JPEG image

Advanced

iccSpecSepToTiff

Apply spectral separation using ICC profiles to TIFF data.
Input: TIFF + spectral profiles

iccV5DspObsToV4Dsp

Convert ICC v5 display+observer profile pair to v4 display.
Input: v5 display + observer profiles

JSON

iccToJson

Convert a binary ICC profile to JSON representation.
Input: ICC profile → Output: JSON

iccFromJson

Build an ICC profile from a JSON specification.
Input: JSON → Output: ICC profile
