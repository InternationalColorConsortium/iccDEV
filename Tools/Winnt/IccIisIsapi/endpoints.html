POST ?mode=tools&input=icc|xml
Converts and validates the upload, generates an ICC PAWG profile assessment, and returns results with downloadable reports and artifacts.

What You Receive

  • A readable profile assessment with security, conformance, and quality indicators.
  • A downloadable PAWG text report that can be saved or shared.
  • Converted ICC, XML, and optional JSON files when each conversion succeeds.
  • A private job workspace containing the uploaded file, reports, and detailed logs.

Operator Notes

  • The endpoint surface stays rooted at iccIisIsapi.dll, so existing smoke checks remain simple.
  • The upload workflow persists uploads, generated files, and logs behind non-enumerated capability URLs.
  • Workspaces expire after 24 hours and the server retains at most 100 jobs.

Analyze An ICC Profile

Choose an ICC profile or ICC XML file. The server will convert and validate it, run the ICC Profile Assessment Working Group report, and provide readable results plus downloadable files.

The Profile Assessment Report checks security, conformance, and quality indicators. A completed report can contain warnings or failures; use the report details to decide what needs review.

Each request also gets a persisted workspace page under ./_tool-work/<job>/, with direct links to the uploaded input, logs, and generated artifacts.

Response Expectations

  • health should return ok with text/plain; charset=utf-8.
  • summary should identify the service without exposing build or commit metadata.
  • xml should return application/xml; charset=utf-8 and begin with an XML declaration.
  • tools should return application/json; charset=utf-8 and one result card per wrapped tool.

Next Step

If the responses are not what you expect, contact the server operator and provide the request status without sharing uploaded artifacts.
