# iccDEV

iccDEV provides open source libraries and command-line tools for reading,
writing, validating, converting, and applying ICC.1 and ICC.2/iccMAX color
profiles.

## Quickstart

| Method | Command |
|--------|---------|
| **Homebrew** | `brew install iccdev` |
| **NPM** | `npm install iccdev` |
| **Docker Pull** | `docker pull ghcr.io/internationalcolorconsortium/iccdev:latest` |
| **Docker Run** | `docker run -it ghcr.io/internationalcolorconsortium/iccdev:latest` |

To build from source, see [Build documentation](docs/build.md).

For a guided overview of libraries, tools, examples, and profile test data, see
[Documentation](docs/index.md).

## About ICC

The International Color Consortium (ICC) promotes open, vendor-neutral,
cross-platform color management. iccDEV, formerly DemoIccMAX, implements tools
and libraries based on the [ICC profile specification](http://www.color.org/icc_specs2.xalter)
and the [iccMAX profile specification](http://www.color.org/iccmax.xalter).

The Windows IIS/ISAPI API reference is maintained separately under
[Tools/Winnt/IccIisIsapi](Tools/Winnt/IccIisIsapi/).
